# Bright Scholar School — Website & School Management System
**Slogan:** *“Pehle Tarbiyat, Phir Taleem”*  
**Campus Address:** Chak No. 47 GB, Samundri, District Faisalabad, Punjab, Pakistan  
**Official Phone & WhatsApp:** 0302-5053993  

---

## 🌟 Overview
Bright Scholar School is an educational institution dedicated to academic excellence alongside moral character building, daily Nazra Quran with Tajweed, and ethical conduct.

This web application combines a public-facing school website with an integrated management system for administrators, faculty teachers, parents, and students.

---

## 🏫 Key Features

### 1. Official School Website
- **Hero & Crest Banner:** High-definition heraldic school branding with the motto *“Pehle Tarbiyat, Phir Taleem”*.
- **Direct 24/7 WhatsApp Support:** Floating and inline WhatsApp buttons to connect directly with school administration at `0302-5053993`.
- **Classes Offered:** Play Group, Nursery, Prep, Class 1, Class 2, Class 3, Class 4, Class 5, Class 6, Class 7, Class 8 / Middle.
- **Transparent Fee Structure:**
  - Play Group to Class 4: **Rs. 2,000 / month**
  - Class 5 to Class 8 / Middle: **Rs. 3,000 / month**
  - Absence Fine Regulation: **Rs. 30 per unapproved absence / chuti**
- **Online Admission Form:** Prospective parents can apply online with real-time submission to the admin queue.
- **Live Notices Board:** Announcements on admissions, exams, holidays, and parent meetings.

### 2. Student Search & 360° Academic Dossier
- Live lookup by Student Name, Roll Number, or Admission ID.
- Detailed dossier displaying:
  - Live attendance percentage, total working days, and absent days
  - Calculated absence fine ledger (`Rs. 30/day`)
  - Monthly fee status (Paid / Partial / Unpaid)
  - Examination and assessment scores with grades (A+, A, B...)
  - Daily Tarbiyat and homework observations
  - One-click print and WhatsApp report slip generator

### 3. Administrator Dashboard
- **Access Credentials:** Password `admin` (or `admin123`)
- **Key Capabilities:**
  - Class Folders (Play Group to Middle) with student enrollment and roster
  - Daily Attendance marker with automatic absence fine calculation
  - Monthly fee voucher generation and payment receipt recording
  - Schedule assessments and record student marks
  - Daily Tarbiyat and conduct observations
  - Online admission applications review & 1-click enrollment
  - School notice board management
  - Customizable absence fine rates and security passwords

### 4. Faculty / Teacher Portal
- **Access Credentials:** Select faculty member, Password `teacher`
- Mark class attendance in one click
- Log daily homework completion and moral behavior remarks
- Enter test scores
- Apply for staff leave

### 5. Parent & Student Portal
- **Access:** Select class, enter Roll Number (e.g. `01`) or Admission ID (e.g. `BSS-101`)
- Real-time attendance rate and absence fine monitoring
- Fee voucher and direct WhatsApp receipt submission
- Examination results and progress card
- Online leave application submission to avoid absence fines
